# Thesis

An ecosystem of asynchronous PHP built on `revolt/event-loop` alone. It rethinks amphp and the older thesis packages
from scratch: it is not a wrapper around amphp and does not depend on it. 64-bit Unix only (`platform.md`).

## Layout

- `packages/<name>/` is one package, published as `thesis/<name>` from a read-only repository of its own.
  `package.php` (the manifest) is the only place of its description and dependencies, see `manifests.md`.
- `tools/monorepo/` is the monorepo tooling (`bin/monorepo`): generated files, the repositories of the packages
  and their split in CI. `tools/php-cs-fixer/` holds our custom PHP CS Fixer rules.
- `monorepo.php` is the root config. Files generated by `make sync` are never edited by hand.
- `agents/<topic>.md` holds rules and decisions that span packages, see "Topics".
  `docs/roadmap.md` and `docs/*-ideas.md` are plans and drafts, not decisions.

## Where knowledge lives

- `AGENTS.md` files and topics are the only memory that survives between sessions. Each one has rules
  (invariants) and decisions (what was rejected and why), and describes how things are now: when we rethink
  something, rewrite the existing text instead of appending a correction, the history is in git.
  Every rule is short, current and in the section it belongs to. Delete what became obsolete, merge duplicates.
- An important finding (an invariant, a decision, a trap, a rejected approach) is written in the same change,
  without being asked, to the narrowest file that covers it: `AGENTS.md` of the package or tool if it is about one,
  a topic if it spans several, a new topic with a line in "Topics" if none fits. A topic over about 8 KB is split
  where its parts are needed apart.
- This file changes only when the user asks or a topic is added: parallel sessions would collide in it.
- `packages/<name>/AGENTS.md` is for those who *change* the package and is loaded only when you read its files.
  How to *use* a package is in its `README.md` or its `skills/`: read them before using a package
  you have not used yet in this session.
- Write `AGENTS.md` only, never `CLAUDE.md`: with the default settings, a `CLAUDE.md` in a directory makes
  Claude Code skip `AGENTS.md` there.
- What a tool enforces (`make fixer`, `make rector`) is not described: the tool fixes the code anyway.
  Why a custom rule is the way it is goes to the `AGENTS.md` next to the rule.

## Topics

`php.md` is imported below and always loaded. Read any other topic in `agents/` before the work it names:

- `errors.md`: calling a PHP function that fails with a warning (files, streams, sockets, processes).
- `fibers.md`: keeping state per fiber, a test that depends on the order of callbacks.
- `manifests.md`: a manifest, a dependency, a new package or file of functions, the public API of a package
  that others use.
- `clients.md`: a client with work in the background (a connection, a reader loop, reconnects).
- `repositories.md`: the split, the repositories of the packages and their settings on GitHub.
- `versions.md`: versions, tags, changelogs and the release.
- `platform.md`: code that depends on the operating system or on the size of `int`.
- `reviews.md`: reviewing a change, acting on the findings of a review.

## Commands

Everything runs in Docker through `make`. `P=<name>` narrows a command to one package. Use it while you work,
the whole monorepo is for the final check.

- `make test P=async`, `make phpstan P=async`, `make fixer P=async`, `make rector P=async`
- `make sync` after changing a manifest or `monorepo.php`
- `make test` starts the services of `compose.yaml` (RabbitMQ) first (`make up`), `make down` stops them.
  An integration test fails without its service, it is never skipped: a skip hides a broken environment
- `make check` runs the checks of CI. CI also runs `make sync` and fails on any change in git,
  so commit the generated files. CI runs the tests on PHP 8.5 and 8.6 (`PHP_VERSION=8.6 make test`)
  and on every Revolt driver: `StreamSelect`, `Uv`, `Ev`, `Event` (`DRIVER=Ev make test`), the other checks
  on 8.5 only

## Git

- Work and commit directly on `main`, do not create branches: the monorepo is in early development,
  branches only get in the way. This rule will change once others contribute.
- Commit only when asked, with a short imperative subject like the existing history. The user pushes.
- Undo a pushed commit with `git revert`, never by rewriting history.
- No `Claude-Session` or other trailers in commit messages and PR descriptions.
- An empty directory is kept by an empty `.gitignore`, never by `.gitkeep`. Delete it once the directory has files.

- `amqp`: AMQP 0.9.1 client for RabbitMQ: publisher confirms, consumers as iterators, reconnects. Requires: async, io, net, time.
- `async`: Structured concurrency for PHP fibers: cancellation is a property of the task tree. Requires: time.
- `cache`: Cache interface with Time\Duration TTLs, a local LRU cache and stampede protection by a keyed mutex. Requires: async, time.
- `exceptionally`: Turns PHP errors into exceptions around a callable, safe when the callable suspends a fiber.
- `formatter`: Formats PHP values, classes, functions and parameters into short strings for error messages.
- `io`: Fast binary I/O: byte buffer with typed encoding, non-blocking streams and stdio. Requires: async, time.
- `net`: Non-blocking TCP and Unix sockets with TLS and an async DNS resolver, cancelled by the task tree. Requires: async, io, time.
- `phpstan-extension`: PHPStan extension for thesis packages: precise types where PHPDoc generics cannot express them.
- `testo-plugin`: Testo plugins for thesis packages: tests on the virtual time of thesis/async. Requires: async.
- `time`: Functions for Time\Duration of PHP 8.6 and a polyfill of it for PHP 8.5, PSR-20 clocks.

Thesis HTTP demo

This PHP server can handle other requests while a handler waits. Open a five-second wait, then try a 250 ms wait. The shorter request can finish first.

Run this in a terminal to send eight requests in parallel to the default address. Each waits for 250–257 ms. The command waits for all eight and prints their total elapsed time, usually about a quarter of a second on an idle machine.

time curl -fsS --parallel --parallel-immediate \
  'http://127.0.0.1:8080/wait/25[0-7]ms'

Visit the error route to trigger an exception. Check the server console for the request logs.

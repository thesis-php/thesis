# Thesis

[![Check](https://github.com/thesis-php/thesis/actions/workflows/check.yaml/badge.svg)](https://github.com/thesis-php/thesis/actions/workflows/check.yaml)
[![PHP](https://img.shields.io/badge/php-8.5%2B-777bb4)](https://www.php.net/)
[![License](https://img.shields.io/badge/license-MIT-blue)](LICENSE)

An ecosystem of asynchronous PHP built on [revolt/event-loop](https://github.com/revoltphp/event-loop) alone:
structured concurrency for fibers, non-blocking I/O, TCP, TLS and DNS, an AMQP client and the tools around them.
64-bit Unix only.

This is the development monorepo. Every package in `packages/` is published as `thesis/<name>`
from a read-only repository of its own, so issues and pull requests go here.

## Development

Everything runs in Docker, see `make help`.

```shell
make i                 # install dependencies
make test P=async      # test one package
make check             # everything CI runs
```

`AGENTS.md` describes the layout, the manifests and the rules of the monorepo.

# Security policy

## Supported versions

Only the latest release of each package gets security fixes. Update to that release to get the fixes.

## Reporting a vulnerability

[Report vulnerabilities privately](https://github.com/thesis-php/thesis/security/advisories/new).
Do not use public issues for vulnerability reports.
Name the package and its version, and describe the problem and how to reproduce it.

Once the fix is released, the advisory is published with it and credits the reporter, unless they ask not to.
